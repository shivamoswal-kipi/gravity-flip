# Gravity Flip — Android One-Click Build

A Godot 4 project for the Gravity Flip 3D mobile game.

### Included
- 3D endless runner
- Gravity flip mechanic
- Neon sci-fi presentation
- Touch/swipe controls
- Crystals, hazards and portals
- Score and best score
- Pause and game-over flow
- Info tab: “DESIGNED BY Totcom Technologies”
- GitHub Actions workflow that builds a debug Android APK online

See `ONE_CLICK_GITHUB.md` for the simplest build instructions.
