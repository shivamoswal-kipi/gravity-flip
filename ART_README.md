# Art & graphics

The game intentionally uses runtime-generated 3D meshes so it can run without Unity assets.

Visual language retained:
- deep-space background
- neon cyan / orange / purple emissive materials
- metallic floating platforms
- futuristic capsule robot with cyan visor and orange core
- purple crystals
- red energy spikes
- glowing portal structures
- fog and glow/bloom

For a premium store release, authored GLB/GLTF models, textures, audio and additional VFX can be dropped into the Godot project without changing the core game loop.
