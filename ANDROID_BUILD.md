# Android export

In Godot 4:
1. Install Godot 4.x and Android export templates.
2. Open this project.
3. Project > Export > Add > Android.
4. Set package identifier to `com.totcomtechnologies.gravityflip`.
5. Enable ARM64.
6. Export APK for direct installation or AAB for Google Play.

No Unity license/editor is required.
